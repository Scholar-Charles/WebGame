*TOWER DEFENSE GAME 2D* 
**TechStack
-Django (Python FrameWork) Back End
-HTML,CSS ,and JAVASCRIPT Front End
-Github for Version Control
-RailWay for Deployment

*GAME FEATURES*

**AUTHENTICATION**
-Create an Account
-Login Account

**GAME FUNCTIONS**
-Profile
-Leaderboards
-Logout
-Mute Sound
-Pause
-Resume
-Build Tower

***REWARDING SYSTEM THROUGH ADS***
1. Buff Rewards
- 2x Damage Buff
- 2x Tower Atk Speed Buff
- 2x Gameplay Speed Buff
- This Ads function has a 5 minute cooldown before you can watch an ad again
2. HP/Live Reward
- +5 Lives
- This ad only appear when a player died a "Click Ads +5 Lives" Button will appear
  on the Game Ended Screen. You will receive rewards after 5 seconds.


*HOW TO RUN THIS GAME LOCALLY*

- Clone This Repository
- Import SQL Script in PGAdmin4
- Make sure Python is available , install Python if not available


**Need to Install**

-pip install django
-pip install psycopg2-binary
 
-After doing this steps now do python manage.py runserver to start
-Click the http://127.0.0.1:8000/  Ctrl+click
